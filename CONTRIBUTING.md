# Cómo contribuir

- Añade tu línea **al final** de `RECOMENDACIONES.md`, nunca al principio ni en medio.
- Formato: `- **Tu nombre**: tu recomendación, breve.`
- Una Pull Request = una línea. No mezcles cambios de varias personas en la misma rama.
- No edites ni borres las líneas de otras personas.
